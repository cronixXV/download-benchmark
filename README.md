# Download Benchmark

Консольная утилита на Node.js для измерения средней скорости скачивания данных с указанного URL.

## Требования

- Node.js версии 18 или выше.

## Запуск

Запуск скрипта с передачей URL в качестве аргумента:

```bash
node benchmark.js <url>
```

Пример:

```bash
node benchmark.js https://github.com/
```

Также можно использовать npm:

```bash
npm run benchmark -- https://github.com/
```

## Принцип работы

1. Принимает URL в качестве аргумента командной строки.
2. Выполняет 10 последовательных HTTP GET-запросов.
3. Дожидается полного получения тела каждого ответа перед началом следующего запроса.
4. Измеряет время выполнения каждого запроса и объём полученных данных.
5. Вычисляет среднее время выполнения одного запроса.
6. Подсчитывает общий объём скачанных данных.
7. Вычисляет среднюю скорость скачивания.

## Результаты измерений

| Показатель                   | Единица измерения | Описание                                                             |
| ---------------------------- | ----------------- | -------------------------------------------------------------------- |
| Среднее время запроса        | секунды (с)       | Средняя продолжительность одного запроса                             |
| Общий объём скачанных данных | МБ                | Суммарный объём полученных данных                                    |
| Общее время скачивания       | секунды (с)       | Суммарное время выполнения всех успешных запросов                    |
| Средняя скорость скачивания  | МБ/с              | Отношение общего объёма скачанных данных к общему времени скачивания |

**МБ/с** — мегабайты в секунду. В реализации используется двоичная система измерения: 1 МБ = 1 048 576 байт.

## Особенности реализации

- Запросы выполняются последовательно, без параллельного выполнения.
- Следующий запрос начинается только после полного получения тела предыдущего ответа.
- Для выполнения HTTP-запросов используется встроенный `fetch` из Node.js.
- Для измерения времени используется `performance.now()`.
- Ошибки отдельных запросов не прерывают выполнение всего скрипта.
- Неуспешные запросы исключаются из итоговых расчётов.
- Средняя скорость рассчитывается по всем успешно завершённым запросам.
